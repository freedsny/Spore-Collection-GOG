# spore-re

[Español](README.md) | [English](README.en.md) | Русский

Нативный порт Spore (вместе с «Космическими приключениями») на Android. Это не эмулятор и не Wine: `SporeApp.exe`
статически перекомпилирован из x86 в C, собран под arm64 и работает поверх моей собственной прослойки Win32/D3D9
(SDL2, DXVK).

> **Проект на очень ранней стадии.** Коммиты будут частые и мелкие: быстрые фиксы, что-то будет ломаться и
> переписываться.

Если нравится порт, можно поддержать на Patreon: **[patreon.com/VinTeRuS](https://www.patreon.com/cw/VinTeRuS/membership)**.

## Установка

Android 10+, arm64 (телефоны примерно с 2019 года). Пока проверено только на Pixel 6. Два APK: `spore.apk` для
видеокарт с Vulkan 1.3 (большинство телефонов), `spore-vk11.apk` для старых видеокарт с Vulkan 1.1 (старые Mali, PowerVR).

1. Скопировать папки игры `Data`, `DataEP1`, `SporebinEP1` и `bp1content` в `Внутренняя память/Spore` на телефоне
   (должен получиться `/sdcard/Spore/SporebinEP1/SporeApp.exe`).
2. Поставить APK, запустить и разрешить «Доступ ко всем файлам».
3. Язык игры — как у телефона; другой выбирается в Настройки (круглая кнопка -> шестерёнка) -> Язык.

## Версия игры

GOG Spore Collection 3.1.0.22, `SporebinEP1/SporeApp.exe` (sha256 в `re/target.sha256`). Другие сборки не подойдут.

## Состояние

- На Pixel 6 работают все стадии (клетка, существо, племя, цивилизация, космос), редакторы, сохранения и звук.
- Управление меняется по стадиям (с короткой подсказкой): тап — клик, удержание — правый клик, один палец крутит
  камеру (существо, космос) или двигает карту (племя, цивилизация), два пальца — поворот, щипок — зум, у существа
  стик и кнопки способностей. Любую кнопку можно перетащить (Настройки -> Раскладка).
- Настройки: разрешение, резкость (фильтр апскейла: при меньшем разрешении интерфейс крупный и чёткий),
  лимит FPS 30-120, качество, размер и видимость кнопок.
- Известные проблемы: в главном меню пока нет «Космических приключений», C++-исключения игры не обрабатываются
  (некоторые профили после модов падают), «Выход» в меню паузы закрывает приложение (это штатный выход игры).

## Что в репозитории

Мой код: хост Win32/D3D9, Android-приложение (Java, сенсорное управление, настройки), скрипты сборки, рекомпилятор
(`third_party/x86recomp`) и патчи для DXVK. Файлов игры и перекомпилированного кода игры здесь нет: этот код
генерируется при сборке из вашей собственной копии игры.

## Сборка (примерно)

Linux, Python 3, Android NDK, установленная игра.

1. `python3 -I third_party/x86recomp/tools/recomp.py --functions all --split 400 --out build/recomp/all`
   генерирует C из игры (настройки в `tools/recomp/game.py`).
2. `make -j3` в `src/native` для десктопной сборки (Linux), `make -j3 PLATFORM=android` для arm64.
3. `android/build-deps.sh` (SDL2, FAudio, DXVK с патчами из `android/patches`), затем `android/build-apk.sh` даёт
   `build/apk/spore.apk`.
4. По желанию оптимизация по профилю: `make PLATFORM=android PGO=gen OUT=../../build/android-pgo-gen/arm64-v8a`,
   поиграть на этой сборке, затем `android/pgo.sh` собирает оптимизированный APK.
